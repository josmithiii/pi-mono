# Pi Agent Workspace

This is the working directory for the pi coding agent running in Docker.

## Layout

- `wiki/` — shared cross-agent knowledge base (read-only mount of `~/wiki/`)
- `AGENTS.md` — agent instructions (shared wiki conventions)
- `CLAUDE.md` — pi project conventions

## Wiki

See `wiki/README.md` for the list of active wikis. Key project state lives in `wiki/projects/`.
